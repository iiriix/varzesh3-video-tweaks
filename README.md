# Video Tweaks for Varzesh3

A Firefox add-on that makes videos on [video.varzesh3.com](https://video.varzesh3.com/) and [video.varzesh3.ir](https://video.varzesh3.ir/) play the way you want.

## Features

- **Sound on:** unmutes the video when it starts playing. The site starts videos muted.
- **No auto play of the next video:** turns off the "auto play next video" toggle.
- **Quality:** selects the highest available quality (for example 1080p) instead of Auto, or a
  quality you choose. If a video doesn't have it, the closest lower one is used.
- **Custom speed:** sets the playback speed. The default is 1.5x, and you can pick any speed the
  site's player offers.

## Settings

Each feature can be switched on or off, and the quality and speed can be chosen, in the add-on's preferences:

- **Desktop:** *Add-ons and themes* → Video Tweaks for Varzesh3 → *Preferences*
- **Android:** *Add-ons* → Video Tweaks for Varzesh3 → *Settings*

Changes apply right away.

## Requirements

Firefox 140 or later on desktop, or Firefox 142 or later on Android.
